## 算法原理

冒泡排序（Bubble Sort）通过相邻元素两两比较，把较大的元素像气泡一样逐步「浮」到序列末尾。每完成一趟，当前未排序区里的最大值就归位到末尾，未排序区长度减 1。

第 $i$ 趟（从 0 计数）只需在 $n-1-i$ 个元素上做相邻比较：

$$
\text{for } j = 0 \text{ to } n-2-i:\quad \text{若 } a[j] > a[j+1] \text{ 则交换}
$$

### 复杂度

- **最好情况**（已有序）：一趟比较后没有任何交换，可提前结束，$O(n)$。
- **平均 / 最坏情况**（逆序）：需要完整的 $n-1$ 趟，共 $\frac{n(n-1)}{2}$ 次比较，$O(n^2)$。
- **空间复杂度**：只在原地交换，$O(1)$。
- **稳定性**：相等元素不会交换，是**稳定**排序。

## 动手观察

右侧实验室输入待排序序列，点「生成推演」。观察每一趟：

1. 黄色柱子表示正在比较的相邻两个元素。
2. 若前者大于后者，两根青色柱子交换位置。
3. 一趟结束，末尾的绿色柱子标记「已归位」，不再参与后续比较。

输入 `6 3 5`，你会看到 6 先和 3 比较并交换，再和 5 比较并交换，第一趟结束时 6 归位。
